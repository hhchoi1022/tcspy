A4애플리케이션 스레드가 예외로 죽으면 스케줄러가 영구 정지 (Shutdown 미실행)CriticalSafetyConcurrency
파일

applications/appscheduler.py, applications/startup.py, shutdown.py, nightobservation.py, biasacquisition.py, darkacquisition.py, flatacquisition.py, autofocus_init.py

위치·의도

각 앱은 run()에서 Thread(target=self._process)를 띄우고, AppScheduler.run_*()는 while action.is_running: sleep(1)로 완료를 기다림.

문제 요소

_process() 안에서 잡히지 않은 예외가 나면 스레드는 죽고 is_running은 True 유지 → 스케줄러가 해당 job에서 멈춤 → 이후 예약된 Flat/Dark/Bias/Shutdown이 실행되지 않음. 새벽에 망원경이 미파킹·냉각 상태로 방치될 수 있음.

개선 제안

_process() 전체를 try/finally: self.is_running=False로 감싸고 예외는 로그+self.exception에 저장. run()이 스레드를 반환하고 스케줄러는 thread.join(timeout)으로 대기. Shutdown은 어떤 상황에서도 실행되도록 독립 워치독(별도 프로세스/cron)으로 분리 권장.
